# FGF10-Hi-C-Analysis

This repository contains analysis and visualization scripts for investigating chromatin interactions at the FGF10 locus using Capture Hi-C and genome-wide Hi-C data from IMR-90 lung fibroblasts and lymphoblasts. Analyses include CHiCAGO interaction scoring, Chicdiff differential interaction testing, chromatin insulation analysis, and integrated genomic visualization using pyGenomeTracks. Selected FGF10-specific results and quality-control summaries are provided. Raw sequencing data, genome-wide contact matrices, and complete Capture Hi-C datasets are not included.
